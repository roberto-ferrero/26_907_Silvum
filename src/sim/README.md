# src/sim

Núcleo de simulación botánica (fase 2): grafo de ejes, unidades de crecimiento,
entrenudos y yemas; reparto de vigor, activación, orientación y engrosamiento.

Reglas: sin dependencias de three.js ni del DOM, determinista por semilla,
unidades SI (metros, años, radianes). Se reescribe a partir de `tree-growth-foundation`.
